# v2.3.0 live checklist

The last feature, and maintenance mode (`docs/16`, v2.3). Same two halves as
every release (`docs/14 §5`): the PR's **preview version** before the tag, then
production.

What ships: YouTube links that cannot play here are left out at import
(`docs/06 §3`) — a Worker change and an app change — plus Astro 7.4.12, the
Svelte integration 9.1.6, music-metadata 12.5.0 with strtok3 10.8.0, and
i18next 27.1.1. The lines below put the shipped bundle through what those do,
and put the new answer through the real Data API and the real player.

      2.2.1's `07aa070b` while the PR's versions were uploaded.
