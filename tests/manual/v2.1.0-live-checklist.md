# v2.1.0 live checklist

The owner's five (`docs/16`, v2.1). Same two halves as every release
(`docs/14 §5`): the PR's **preview version** before the tag, then production.

Desktop browser, Chromium first — Claude desktop's built-in browser plays real
YouTube, which a Playwright-driven browser cannot. Real lists for the playlist
lines: a channel's uploads, e.g. `UUuAXFkgsw1L7xaCfnd5JJOw`, as
`https://www.youtube.com/playlist?list=UUuAXFkgsw1L7xaCfnd5JJOw`.

## Before anything — the deploy model

- [ ] **Pushing the branch did not deploy it.** `pnpm wrangler deployments
      list` shows no new deployment after the push; `versions list` shows a new
      version.

## Blocking — on the preview version

- [ ] **About reads 2.1.0.**
- [ ] **The gate is back, at v2.1** (a fresh profile, or Settings → Reset). It
      lists the AI point. **Decline and go back** from a page opened via the
      landing returns to the landing, and nothing is stored; Accept works.
- [ ] **The legal pages read 2.1**, in both languages:
      - Disclaimer §7 names Claude Code, Anthropic, PBC, Claude Opus 4.8 and
        Claude Opus 5.5;
      - Privacy §6 names requests for addresses that do not exist;
      - Third-Party Notices lists the YouTube Data API.
- [ ] **Playlists.** YouTube → Playlists → paste a real list plus a bogus
      `PLzzzzzzzzzzzzzzzz`. Check that:
      - the real list's videos load in playlist order, capped at 50, with the
        toast naming TT-YT-003 for the rest;
      - the bogus list is TT-YT-010 and does not sink the other.
- [ ] **A Mix is refused with no request:** a `&list=RD…` link → TT-YT-012, and
      the Network panel shows no `/api/yt/playlists` call.
- [ ] **A playlist's video plays** in the real player, and the next one follows
      at its end.
- [ ] **The fitted countdown, with real lengths.** Videos: paste two short
      links → Repeat off → Khớp độ dài → the note "follows the queue" shows →
      Start → remove the second link → the countdown drops by its length.
      Repeat on, then the same: it does not.
- [ ] **Diagnostics** list one TT-PLY-107 for the removal; the console is clean.
- [ ] `TT_CSP_BASE=<Version URL> pnpm verify:csp` — six cases.

## After the signed tag — production

- [ ] **About reads 2.1.0.**
- [ ] **Exactly one new deployment** in `pnpm wrangler deployments list`.
- [ ] **The gate shows v2.1** to a profile that accepted 2.0.
- [ ] **A playlist imports** on `https://ticktune.net/app/`.
- [ ] `TT_CSP_BASE=https://ticktune.net pnpm verify:csp` — six cases.
