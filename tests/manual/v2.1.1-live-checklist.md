# v2.1.1 live checklist

The tag parser, music-metadata 12.3.3 (`docs/16`, v2.1.1). Same two halves as
every release (`docs/14 §5`): the PR's **preview version** before the tag, then
production.

Only the local importer's parser changed. The lines below put the shipped
bundle through what it reads. Use the repo's own fixtures in
`tests/e2e/fixtures/`:

- the Vietnamese ID3v2.3 (UTF-16) and ID3v2.4 (UTF-8) tags, ID3v1, MP4 and
  Vorbis;
- the cover;
- the 11-minute file.

## Before anything — the deploy model

- [ ] **Pushing the branch did not deploy it.** `pnpm wrangler deployments
      list` shows no new deployment after the push; `versions list` shows a new
      version.

## Blocking — on the preview version

- [ ] **About reads 2.1.1.**
- [ ] **Tags survive the new parser.** Playlist → import `vi-id3v23-utf16.mp3`,
      `vi-id3v24-utf8.mp3`, `vi-mp4.m4a`, `vi-vorbis.oga` and `with-cover.mp3`.
      Each row shows its Vietnamese title and artist with no mojibake, and a
      length. The cover fixture shows its art.
- [ ] **The 10:02 limit still reads the length:** `over-limit-11min.mp3` is
      refused with TT-IMP-002.
- [ ] **A run plays:** Match → Start → the first track is heard, and the
      console is clean.
- [ ] `TT_CSP_BASE=<Version URL> pnpm verify:csp` — six cases.

## After the signed tag — production

- [ ] **About reads 2.1.1.**
- [ ] **Exactly one new deployment** in `pnpm wrangler deployments list`.
- [ ] `TT_CSP_BASE=https://ticktune.net pnpm verify:csp` — six cases.
