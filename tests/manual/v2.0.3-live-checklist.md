# v2.0.3 live checklist

The `/api/*` rate limit (`docs/16`, v2.0.3). Same two halves as every release
(`docs/14 §5`): the PR's **preview version** before the tag, then production.

Only the Worker and `wrangler.jsonc` changed in behaviour; the client bundle
differs by its version string alone. So the lines below are the budget itself,
that the endpoints still answer inside it, and that nothing static moved.

⚠️ The budget is per IP and per edge location, and a preview shares its
counters with production (same `namespace_id`): after a burst, **wait a full
minute** before the next line, or it reads the burst's 429.

## Before anything — the deploy model

- [ ] **Pushing the branch did not deploy it.** `pnpm wrangler deployments
      list` shows no new deployment after the push; `versions list` shows a new
      version.

## Blocking — on the preview version

- [ ] **About reads 2.0.3.**
- [ ] **The budget fires.** 70 rapid calls to
      `<preview>/api/yt/oembed?id=nope` → about 60 × `400 invalid_id`, then
      `429 {"error":"rate_limited"}` — `application/json`, `nosniff`,
      `max-age=0`, no `Access-Control-Allow-Origin`.
- [ ] **Inside the budget, both endpoints answer** (a minute later):
      `/api/yt/oembed?id=dQw4w9WgXcQ` → 200 with a title;
      `/api/yt/durations?ids=dQw4w9WgXcQ` → 200 with a length in ms.
- [ ] **Nothing static is counted.** 70 rapid calls to `/` → all 200; an
      unknown path → the 404 page.
- [ ] `TT_CSP_BASE=<Version URL> pnpm verify:csp` — six cases.

## After the signed tag — production

- [ ] **About reads 2.0.3.**
- [ ] **Exactly one new deployment** in `pnpm wrangler deployments list`.
- [ ] **61 rapid calls to `/api/*` → 429** — `docs/10 §11`'s box, open since
      P4.
- [ ] `TT_CSP_BASE=https://ticktune.net pnpm verify:csp` — six cases.
