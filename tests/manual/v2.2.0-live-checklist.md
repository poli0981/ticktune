# v2.2.0 live checklist

Accessibility: the statement, and the barriers it would have to admit
(`docs/16`, v2.2). Same two halves as every release (`docs/14 §5`): the PR's
**preview version** before the tag, then production.

Run by the session that cuts the tag. Real YouTube runs in Claude desktop's
built-in browser (`tests/manual/yt-matrix.md`); the rest is a headless Chromium
script with the analytics beacon fulfilled locally and the locale `vi-VN`, as
`playwright.config.ts` pins it.

## Before anything — the deploy model

- [ ] **Pushing the branch did not deploy it.** The newest deployment stays
      2.1.1's `aad8081b` while the branch's version is uploaded.

## Blocking — on the preview version

- [ ] **About reads 2.2.0.**
- [ ] **Keyboard.**
  - With the mouse unused, the gate clears, a file is picked from the drop zone,
    and a run starts.
  - The drop zone shows a ring when its picker has focus.
  - `Space` on a focused ⏭ skips, and the run keeps playing.
  - With ⚙ → Phím tắt → "Phím tắt một ký tự" off, `S` and `M` do nothing, and
    the setting survives a reload.
- [ ] **Screen-reader surfaces.**
  - The player's `role=timer` reads "Thời gian còn lại: …" in words.
  - The bottom bar's buttons stay in the accessibility tree once it has idled.
  - Finished takes focus on its heading.
- [ ] **Forced colours.** Chromium emulation, against the preview:
  - the landing gauges read 10:02 / 95 / 91:00 / 50, not 88:88;
  - VI is highlighted among VI/EN/JA;
  - a checked switch differs from an unchecked one.
- [ ] **The landing.**
  - "Dừng video minh hoạ" swaps the video for the still, from the keyboard.
  - The footer carries accessibility@poli0981.dev and the statement link.
- [ ] **The gate, zoomed.** A desktop tab at 900 px wide shows the notice with
      the Ctrl+0 line in all three languages. At 1440 px, the app loads.
- [ ] **Real YouTube** (built-in browser).
  - The player's iframe has a `title`: "YouTube video player", then the video's
    own.
  - A link that cannot play shows the card. Its alert holds the title and
    cause, and the counter ticks outside it.
- [ ] **A run plays with a clean console.** No error, no
      `securitypolicyviolation`, no failed request.
- [ ] `TT_CSP_BASE=<Version URL> pnpm verify:csp` passes all six cases. The
      inline script's hash is unchanged: `build` printed the same
      `sha256-cuTkHu…` as v2.1.1.

## After the signed tag — production

- [ ] **The tag's signature is verified** against a keyring holding only
      `https://github.com/poli0981.gpg` before the push. `deploy.yml`'s verify,
      deploy and release jobs are green.
- [ ] **About reads 2.2.0.**
- [ ] **Exactly one new deployment** after 2.1.1's `aad8081b`.
- [ ] `TT_CSP_BASE=https://ticktune.net pnpm verify:csp` passes all six cases.
- [ ] **GitHub's Community Standards page** ticks Accessibility and the pull
      request template. The issue chooser offers "Accessibility barrier".
