# v1.1 live checklist — the full review

v1.1 is the first release under the **tag-only** model (`docs/14 §5`), so this
list has two halves that run at different times:

1. **Before the merge**, on the PR's **preview version** — the URL Workers
   Builds posts on the PR. It runs the real Worker, `_headers` and CSP, which
   `astro dev`/`astro preview` do not, and it is a fresh origin, so every visit
   starts as a first run.
2. **After the signed tag**, a short re-check of production itself.

Run on a **desktop** browser. Chromium first; the lines marked 🦊 / 🧭 also in
Firefox / Safari.

> **Result, reported by the owner after v1.1.1 (2026-10-20):** Firefox and
> Safari both fine — the 🦊 / 🧭 lines; Lighthouse on `/`, desktop:
> **99 / 100 / 100 / 100**. v2.0 fixed what that report flagged (the hero
> video's cache lifetime), and Lighthouse CI now runs on every PR
> (`docs/13 §5`). The boxes below stay as the run left them: a box is ticked by
> whoever ran the line, never afterwards.

## Before anything — the deploy model itself

- [ ] 🔴 **Pushing a branch did not deploy it.** After the first push,
      `pnpm wrangler deployments list` shows **no** new deployment, while
      `pnpm wrangler versions list` shows a new version. If a deployment
      appeared, Workers Builds still runs `wrangler deploy` — stop and fix the
      dashboard (`docs/10`, `docs/14 §5`) before pushing anything else.

## Blocking — on the preview version

### Analytics and Legal 1.1

- [ ] **The beacon is in the page and allowed by the CSP.** DevTools → Network:
      `beacon.min.js` loads from `static.cloudflareinsights.com`, its report goes
      to `cloudflareinsights.com`, and the Console shows **no** CSP violation —
      on `/`, `/en/`, a legal page and `/app/`.
- [ ] **The gate discloses it.** A first visit to `/app/` shows the gate with
      the analytics point, and Accept works by keyboard alone (`Space`, `Tab`,
      `Enter`).
- [ ] **The legal set reads `Version 1.1 · 2026-10-20`** on all eight pages, VI
      and EN, and the contact addresses are the role ones (privacy@, legal@,
      copyright@ — `@poli0981.dev`).
- [ ] **`/.well-known/security.txt`** is served as text, with
      `Contact: mailto:security@poli0981.dev` and an `Expires` in 2027.
- [ ] **The landing footer** lists press@, collab@ and security@ as mail links.

### The runtime fixes

Each of these was a shipped defect; each has an E2E spec, but the spec runs
against a stubbed YouTube and a synthetic drop.

- [ ] **Restart inside the fade.** Countdown ~10 s with End → Restart; when it
      ends, the next run **plays music** and ⏯ shows pause, not play.
- [ ] **Remove the playing track** (Playlist, right-click → Remove). The next
      track starts; nothing is skipped when it ends.
- [ ] **A broken file in a playlist** (rename any non-audio file to `.mp3`):
      its row is struck through and the next track plays.
- [ ] **⏭ while paused stays silent** — local and YouTube.
- [ ] **Modifier keys belong to the browser**: `Ctrl+F` opens find (not
      fullscreen), `Ctrl+S` does not open Settings, and `Alt+↑` on a queue row
      reorders **without** changing the volume.
- [ ] **Reset app in an English browser** comes back in English.

### The redesign 🦊 🧭

- [ ] **Every screen is the new design**: gate, Setup (two modules, Source and
      Timer), player in all three modes, Settings, Finished, the info modal, the
      landing pages, a legal page, the 404.
- [ ] **Setup fits a 1280×720 window** with one staged track — Start visible
      without scrolling.
- [ ] 🔴 **The YouTube player is never covered.** YouTube mode, a **2-hour**
      countdown, window at 1280 and at 1024 wide: the player is fully on screen
      and nothing paints over it — open Settings, open the info modal, let the
      bottom bar appear.
- [ ] **The bottom bar fades out after 4 s and back in on a mouse move** — a
      fade, not a cut (it used to be a cut).
- [ ] **Hide scrollbars**: Settings → Display → Hide scrollbars. The queue and
      the settings sheet lose their bars and still scroll by wheel and keyboard;
      it survives a reload; the landing and legal pages keep their slim bars.
- [ ] **Vietnamese diacritics render in the display face** — "NGUỒN PHÁT",
      "HẸN GIỜ", "HẾT GIỜ" — with no fallback glyphs.
- [ ] **Reduced motion** (the real OS setting): no entrance animation on the
      gate, the settings sheet or the Finished stamp; the tally does not pulse.

      origins, and `Strict-Transport-Security` is present.
- [ ] `curl -sI 'https://ticktune.net/api/yt/oembed?id=jNQXAC9IVRw'` → `200`,
      `application/json`, `x-content-type-options: nosniff`, and **no**
      `access-control-allow-origin`.
- [ ] **A profile that accepted 1.0 is asked again — once.** Accept, reload, and
      the gate stays away.
